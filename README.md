# mammaの店 LP（叩き台）

埼玉県蓮田市の和食割烹・小料理「mammaの店」の1ページLP。素のHTML/CSS/JS。

- PC（1024px以上）：中央430pxのステージ、左に店名、右にページ内ナビを固定
- SP：ステージを全幅で表示

確認用の試作。店主の確認が済んでいない項目は仮の値で埋め、`<span class="kari">` で囲んで薄い点線を付けている。
確定したら値を直して `kari` を外す。全部確定したら、上部の帯（`.bar-draft`）と `<meta name="robots" content="noindex">` を消す。
写真は点線の枠のまま（Instagram写真の転用許可待ち）。

## 仮で入れている値

| 項目 | 仮の値 |
|---|---|
| ページの目的 | 会員・紹介客向け。紹介があれば初めての方も予約可 |
| 予約方法 | Instagram DM（希望日・人数・紹介者名） |
| 料金 | おまかせ お一人様 4,000円〜（税込・飲み物別） |
| 営業時間 | 17:00〜22:00（LO 21:30） |
| 駅から | 蓮田駅東口から徒歩1分 |
| 席数・貸切 | 12席、貸切は8名から相談 |
| お飲み物 | ビール・日本酒・焼酎・ワイン・ソフトドリンク |
| お通し | 三点盛り、おかわり無料 |
| 電話・メール | 載せない（DMに一本化） |
| 店名・ロゴ | mammaの店、ロゴなし |

## 要確認リスト（店主に聞く順）

1. **LPの目的**：会員・紹介客向けの案内か、会員募集も兼ねるか。予約導線（`#annai` の「ご予約について」）はこれで決まる
2. 正式店名・ロゴ
3. 料金体系（おまかせ一式／アラカルト）、価格を載せるか。旧バル時代の価格は使わない
4. 営業日（土曜のみか、金・日もあるか）、閉店・ラストオーダー
5. 駅からの表記：徒歩30秒／徒歩1分
6. 予約方法・連絡先（電話 050番号が使えるか／DM／メール）、入会・紹介の要否
7. 席数（12席で確定か）、貸切・小宴会
8. ドリンクの現行ラインナップ
9. お通し三点盛り・お代わり無料を続けるか
10. Instagram写真の転用可否、店内・女将の写真
11. 旧洋メニュー（ラクレット等）を残すか。叩き台では「女将」節で前身店として触れるだけ
12. Googleマップの住所（旧2F表記）を誰が直すか
