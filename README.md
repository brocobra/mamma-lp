# mammaの店 LP（叩き台）

埼玉県蓮田市の和食割烹・小料理「mammaの店」の1ページLP。素のHTML/CSS/JS。

- PC（1024px以上）：中央430pxのステージ、左に店名、右にページ内ナビを固定
- SP：ステージを全幅で表示

本文中の `【要確認：…】`（赤茶の点線）と点線の写真枠は、店主の確認待ちの箇所。
`<meta name="robots" content="noindex">` を入れてあるので、公開前に外す。

## 要確認リスト（店主に聞く順）

1. **LPの目的**：会員・紹介客向けの案内か、会員募集も兼ねるか。予約導線（`#annai` の点線枠）はこれで決まる
2. 正式店名・ロゴ
3. 料金体系（おまかせ一式／アラカルト）、価格を載せるか。旧バル時代の価格は使わない
4. 営業日（土曜のみか、金・日もあるか）、閉店・ラストオーダー
5. 駅からの表記：徒歩30秒／徒歩1分
6. 予約方法・連絡先（電話 050番号が使えるか／DM／メール）、入会・紹介の要否
7. 席数（12席で確定か）、貸切・小宴会
8. ドリンクの現行ラインナップ
9. お通し三点盛り・お代わり無料を続けるか
10. Instagram写真の転用可否、店内・女将の写真
11. 旧洋メニュー（ラクレット等）を残すか。叩き台では「女将」節で前身店として触れるだけ
12. Googleマップの住所（旧2F表記）を誰が直すか
